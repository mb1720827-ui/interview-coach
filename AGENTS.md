# For AI coding agents

When someone asks you to interview them on their code, quiz them on a project, or help them prepare to explain a repository in a job interview, follow [`skills/mock-interview/SKILL.md`](skills/mock-interview/SKILL.md).

Read-only: never modify the repository you're interviewing them on. Progress between sessions is kept in `~/.interview-coach/<repo-folder-name>.md`.
